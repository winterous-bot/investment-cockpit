Scope: day/week/month, no minute purchases, no probability model, no live UI. Input daily + adj_factor (stock), index_daily (benchmark), daily_basic, exchange calendar. Front-adjust to analysis date before aggregation. No future price records; incomplete current week/month flagged by calendar. Price computations retain full precision; volume remains hands and amount thousand CNY. EMA 12/26/9 seeded from first close; MACD=2*(DIF-DEA). RSI 6/12/24 Chinese SMA recursive formula; BOLL 20, sample standard deviation (n−1) ×2 (R1 convention under validation); volume MA5/10 hypothesis. Short histories return unavailable; no synthetic missing bars. Five benchmark returns on matched dates; optional ATR14, 20-day realized volatility, relative volume and 52-week distance. 

Live validation uses three explicitly public sample symbols; screenshot fixture is transcribed from 002475.SZ 2026-11-27 images, not fitted to values. Compare individually, report every mismatch; a successful workflow does not mean all reference indicators match. Any discrepancies require resolution before freezing the foundation. No raw licensed data, pool contents, tokens or secrets published. No production workflow integration or model probability estimates until approved.
