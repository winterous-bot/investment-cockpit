# V1.0-A implementation scope

Approved draft rules implemented in technical/model_a.py: T/M, short/medium aggregation, V, broad relative-strength R, D, alignment, medium structure, weekly reversal candidate and confirmation, preliminary location/risk. No modification to the frozen foundation, no market/industry context or live action recommendations. C retains full breakout/retest and action integration. No probabilities. No production deployment.

Operational clarifications: shared analysis-day adjustment anchor for comparisons within a clean segment; exact exchange-session windows for broad RS, same index set per horizon, require three indices and 75% coverage, no stale/future benchmark accepted. Completed weekly evidence requires last exchange session of the period; if a stock did not trade on that day, it cannot establish that completed signal. A developing week can only form a provisional reversal candidate. After a major quality break, previous recursive state also must satisfy frozen warmup. Missing required input never becomes a zero vote. Partial diagnostics may be shown without composite readiness. Conservative preliminary risk flags include missing levels/unknown inputs; no final execution instruction. Numerical comparisons use a 1e-12 floating boundary guard; directional sums rounded to 10 decimal digits only to prevent classification drift, not input rounding.

Validation: hand-computed synthetic cases, boundary and missing/stale data tests, frozen foundation tests, three public stocks on three preselected dates (2026-10-30, 2026-11-20, 2026-11-27), exact comparison with separately rebuilt historical prefixes. Calendar range verified from provider. Test success is computational validation, not prediction accuracy or parameter optimization. Market/industry context and full breakout/retest remain unimplemented. Historical vendor revisions, limited external precision sample and frozen warmup restrictions carry forward.
