Status: proposed research rules, not calibrated or deployed. Base: frozen/technical-foundation-v1.0 (6b89f3846bd8cca8e975b62167e71140e2ad2cd3). Scope: daily, weekly, monthly only; no minute data, no probability claims, no production changes. All decisions as of China exchange close, UTC+8. New inputs must pass timestamp, source and coverage checks. Do not modify foundation algorithms; use QualityHistory.view and its guarded feature fields; later training must use training_admission and full verified exchange calendar. If combined readiness fails, allow only explicitly marked available single-cycle diagnostics; no combined score or action candidate. A missing feature is null, not zero. Any data revision requires a new version and validation.

## 1. Directional primitives
sgn_delta(x,t)=+1 if x>t, -1 if x<-t, else 0. Use exact unrounded values.
For each frequency f:
T=100*(.30*s(C/MA20-1,.0025)+.20*s(MA5/MA10-1,.0025)+.25*s(MA10/MA20-1,.0025)+.25*s(MA20/MA20[t-5]-1,.005)).
All four required; t-5 means five prior bars of same frequency, derived from guarded history; no forward fills. T>=50 bullish, T<=-50 bearish, otherwise range; abs(T)>=75 strong. Momentum M=100*(.40*s(MACD/close,.001)+.35*s((MACD-MACD[t-1])/close,.0005)+.25*RSI12vote), RSI12vote=+1 above 55, -1 below 45, else 0. RSI6 and 24 used for explanation/risk (RSI6>=80 overbought, <=20 oversold, not automatic reversal). Current MA/MACD formulas unchanged. Use guarded prior state for the slope and MACD difference. Missing required input blocks component. Do not reconstruct unguarded histories.

Short horizon daily/weekly/monthly weights .65/.25/.10; medium .25/.50/.25. T_h and M_h are weighted sums. Weekly/monthly developing periods can contribute to preliminary state; any confirmed weekly/monthly event must be evaluated on the most recent completed period, with its own historical as-of state. Output provisional flag and latest completed date.

Volume/price V=100*sign(C-prevC) if volume/current previous 20-bar average >=1.5 and abs(C-prevC)>=0.5*ATR14, else 0. Use day for short, last completed week for medium; weekly ATR14 computed using frozen Wilder method on guarded bars, no synthetic volumes. Ratio <=.75 is low-volume context, not a directional vote. Incomplete week volume never compared with completed weeks. Missing data blocks V.

Relative strength R: fixed broad reference = weighted average of per-index relative return values (HS300 .30, CSI500 .25, CSI1000 .25, CSI2000 .20); require >=75% weight and >=3 same-date indexes, renormalize and disclose coverage, no substitute. Short uses average of RS5 and RS20; medium RS20 and RS60. Each comparison vote = s(RS in percentage points, threshold 1 for 5d, 2 for 20d, 3 for 60d); R=100*mean of the two votes. Keep industry-relative values separate; require point-in-time membership and same taxonomy/date. RS positive/negative is relative, not absolute direction.

Directional evidence D_h=.55*T_h+.20*M_h+.10*V_h+.15*R_h; [-100,100], no conversion to probability. All required; otherwise no composite. D>=50 strong positive, 20<=D<50 positive, -20<D<20 mixed, -50<D<=-20 negative, D<=-50 strong negative. T remains separate from D. Multi-cycle alignment is a label, not extra score (avoid duplicate trend votes): all T>=50 bullish alignment; all <=-50 bearish alignment; daily >=50 and weekly <=-50 rebound in downtrend; daily <=-50 and weekly >=50 pullback in uptrend; otherwise mixed. Medium bullish label requires weekly bullish and monthly not bearish; medium bearish vice versa; otherwise conflicting/repair/pullback, not confirmed reversal. Reversal candidate after prior completed weekly bearish, current weekly T>=50, close above MA20, MA20 slope positive, MACD positive; confirmation requires two successive completed weeks meeting conditions. Reverse conditions for bearish reversal. Thresholds are hypotheses; candidate signals are not proven profitable.

## 2. Market and industry context (not additional votes)
Reuse four-benchmark market index scoring: 1 point each close >=MA20, >=MA60, >=MA250, MA20 above its level five bars earlier, 20-day return positive. Fixed weights .30/.25/.25/.20; require >=75% and >=3 same-date indices. Score 0–5: <=1.5 weak, >=3.5 strong, otherwise mixed. Shanghai Composite for display not fifth vote. Existing automated breadth and liquidity separate (coverage >=80%, as-of exact date); do not import manual macro/policy scores or stale market_signals.json. Weak market + weak breadth (both <=1.5) = defensive overlay; insufficient breadth means unknown, not neutral. Existing user-confirmed severe risk blocks new exposure; do not auto-write risk matrix.
Industry: point-in-time SW2021 L1 mapping, historical membership dates and same taxonomy daily index. Same five-rule index trend if history sufficient. Industry RS20 vs broad (above +2pp outperforming, below -2pp underperforming). Stock vs industry RS5/20/60 reported independently. No current membership backfill or stale industry radar as historical label. Missing industry -> incomplete context; no high-confidence action candidate, no fabricated neutral. Industry radar is contextual cross-check, not duplicate vote. Existing Tushare entitlements need live coverage validation.

## 3. Location and independent risk
Use guarded daily ATR14, daily MA20/60/250, prior20/60 high/low, guarded weekly/monthly MA20 and prior20 highs/lows. Use only values <=asof, no centered pivots. Candidate levels strictly below/above current close; cluster sorted levels only if entire cluster span <=0.5 daily ATR, preserve evidence source. Nearest support and resistance zones; missing zone -> no reward/risk. For research risk reference, stop/invalidation = lower edge of support -0.5 ATR (must be >0 and below price); target = lower edge of resistance; R=(target-close)/(close-invalidation), not a return forecast. No forced target if none exists. Distance to MA20 / ATR >=2 OR RSI6>=80 = extension warning. risk distance / close >=8% OR ATR14/close >=5% = high risk; ratio R<2 = unfavorable. These are tentative absolute guards, not position sizing. No execution, no leverage suggestion. Existing 5x5 portfolio constraints retain precedence.
Candidate breakout: close above previous 20 or 60 bar high and volume >=1.5x previous20 average; confirmation only after next actual close remains above pre-break level, not future data used now. Confirmed week/month uses completed period only. Retest candidate: after a prior confirmed breakout, observed low reaches zone within 0.5 ATR, close reclaims level, volume <=1.0 prior20 average; no future confirmation. If prior confirmed level is unavailable, no retest classification.
Action output hierarchy: blocked/stale/missing -> evidence insufficient; severe user risk or weak market+weak breadth -> defensive/no new exposure; extension/high risk/R<2/unknown level -> observe/no chasing; bullish weekly and daily D>=20, no adverse monthly, valid context, candidate breakout or retest and R>=2 -> conditional opportunity (not buy instruction); existing holding trend deterioration (weekly bearish or confirmed support break) -> review risk/reduce candidate; otherwise watch/hold-review. No automatic trades, position size or sale. Action is conditional on user-confirmed portfolio risk and actual execution constraints.
