# 行业热点雷达 V1.0
独立研究模块，尚未接入正式PWA。使用现有 TUSHARE_TOKEN；本版仅使用收盘数据。申万2021官方分类（31个一级、134个二级，实际可发布子集与覆盖以接口为准）；宽基按沪深300/500/1000/2000 30/25/25/20（中证2000发布前归一化前三）。同层5日超额排序。
- 关注度 = 最近5交易日行业成交额占31个申万一级行业成交额合计的平均值 / 此前20交易日相同平均值。不是真实市场净流入，不将一级和二级重复求和。
- 排名改善 = 5日前排名分位减当前排名分位，0为最强。持续性 = 最近5日至少3日处于前25%。
- 规则优先级：退潮（5日超额<0、排名分位恶化>=15个百分点、关注度<1）；过热（5日涨幅>=12%或距MA20>=12%且关注度>=1.5）；启动（前25%、5日超额>=2pp、排名改善>=20pp、关注度>=1.2、5日正收益）；主升（前25%、5/20日超额正、持续性>=3日）；潜伏（关注度>=1.2、排名改善>=10pp、5日超额非负）；其余普通。缺失不分类。阈值仅是待验证的可解释研究条件。
- 5日个股广度及前五领涨：当前申万成分、沪深上市股、连续5日可用日涨跌幅复合、至少80%行业样本有效且>=5只。仅当前观察，不使用今天成分历史回测；不把领涨股当买点。
- 历史验证：2022年起每周最后交易日的启动组与相同日期、相同数量5日涨幅前列对照组比较；次交易日收盘至5/10/20个交易日后收盘，计算超额中位数、正超额比例、未来行业排名前25%比例及最大回撤。不是可交易组合回报；重叠样本，2024+非盲测；历史行业分类修订风险。
- 缺失/过期：最近8交易日无足够行情则失败；旧快照注明实际数据日期，不当作当日数据。未验证权限或覆盖不足时不显示个股广度。
- 输出：radar.html（可筛选和搜索的离线报告）、radar_snapshot.json（派生当前指标）、validation.json（汇总统计）。只上传短期工作流成果，不提交原始付费行情、不将数据部署到公开Pages；公开仓库的Actions成果也不是私有存储，长期使用前须确认授权并迁移私有数据输出。现有main与PWA不变。
