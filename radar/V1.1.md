# 行业热点雷达 V1.1
保留 V1.0 原阶段规则，新增独立观察标记，不将标记视为买卖信号。
- 关注度异动：近5日成交额占比 / 前20日均值 >=1.3；排名跃升：5日前排名分位减当前分位 >=20个百分点。
- 量价前兆：关注度>=1.3，5日涨幅0%至3%，5日超额非负，排名改善>=10个百分点。放量下跌、放量相对弱势单独提示，非买点。规则为初始研究假设，不是拟合后的最佳阈值。
- 行业扩散：当前及此前5日累计正收益股票占比，使用相同的25日连续有效样本；变化>=15pp为扩散增强，<=-15pp为收窄。现时成分须在25日观察期开始时已纳入；覆盖不足则留空。未进行股票历史回测。
- 领涨股按5日涨幅排名；潜在补涨观察需行业5/20日均涨、个股5日正收益低于行业、较此前5日改善、20日正收益、成交额比>=1.2。仅供进一步研究。
- 近20交易日行业轨迹为逐日因果指标。历史验证2022起，周末信号，次日收盘起算5/10/20交易日；分别验证前兆、关注度及跃升，对比同日同数量涨幅排名和关注度排名。无成本，样本重叠，2024+非盲测。
- 使用公开仓库的研究成果附件（保留3天），不公开部署Pages、不提交原始付费数据；附件并非私有存储，后续须确认授权并改为私有运行。现有正式工具不变。
