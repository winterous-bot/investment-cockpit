# 个股深度基本面研究 V1.0（研究原型）
五个样本来自既有独立年报核对基准：立讯精密、北方华创、长川科技、汇川技术、宁德时代。不是选股结果。以20261125为数据截面、共通2026Q3财报，单股接口按两年区间请求，截止日前已公告合并报表；同日冲突排除，缺失不填0。五年年度数据、12季度单季拆分、TTM、ROIC/ROE、毛利率及扣非净利率、现金转化、资产负债率、流动比率、应收存货；季度加速为描述标签，保留1000万/1%低基数保护，不继承独立交易策略。使用原成长股规则判断预设，不符合仍展示基础研究。风险核查阈值为人工复核提示，不是预测评分。近36个完整月末正PE参考、同日认证成长股截面才允许同行参考；冻结V1.4.2重构与求解器原样调用，基础扫描不适用即不计算。五家2025年报四项原始数值既有独立来源再次比对，不能证明完整FCFF/ROIC/EV准确。所有个股报告AES-GCM加密，公开日志仅汇总。
