# 投资决策驾驶舱 v1.1（iPhone 版）

这是一个可以实际使用的 **iPhone PWA（主屏幕网页 App）**，包含手机界面、A 股行情自动采集、观察池分档目标仓位、持仓汇总、融资风险预算、超限和价格触发提醒、JSON 备份与 CSV 汇总导出。

**未接入券商账户；不会下单。** 页面打开后显示行情快照及提醒，不提供手机后台远程推送。账户和持仓数据仅存储在该设备的浏览器/网页 App 本地存储中。

## 最快部署（GitHub Pages）

1. 解压本项目，确保下列文件和目录完整保留：`index.html`、`style.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`assets/`、`data/`、`scripts/` 和 **`.github/workflows/`**。
2. 在 GitHub 新建一个仓库，例如 `investment-cockpit`，推荐使用 public 仓库（代码与**公开行情**可公开，但**个人仓位不要上传到仓库**）。将解压后的**文件内容**放在仓库根目录，而不是多包一层文件夹。
3. 在仓库的 **Settings → Pages → Build and deployment** 中选 **Deploy from a branch → main → /(root)**，保存。
4. 在 **Actions** 中找到“每日A股行情快照”，点击 **Run workflow**，第一次手工执行以生成 `data/quotes.json`；若 Actions 权限受限，检查 **Settings → Actions → General → Workflow permissions** 是否允许该工作流提交数据。
5. 等待 Pages 部署完成。访问 `https://你的GitHub用户名.github.io/investment-cockpit/`（只是网址格式示例，实际依你的仓库名而定）。
6. 在 iPhone 18 Pro Max 的 Safari 中打开这个网址，点**分享 → 添加到主屏幕 → 作为 Web App 打开 → 添加**。此后可从主屏幕进入。

> 如果用 iPhone 的 GitHub 网页版上传，注意**隐藏目录 `.github` 必须保留**；它负责日常行情自动更新。首次部署在电脑端保留目录结构更方便。GitHub Pages 免费和发布权限受账户/仓库类型限制，以 GitHub 当时规则为准。

## 盘中一键刷新观察股（v1.1 扩展）

手机App右上角圆形刷新按钮，以及「设置 → 行情自动更新 → 盘中获取观察池最新价」，现在会直接查询本机观察池与持仓中的股票代码；成功后立刻更新市值、净资产、融资比例和风控告警。它是按需查询，**并非交易所直连实时推送**。非交易时段返回最近交易价，请查看每只股票的交易时间。

### 默认方式：浏览器直连

点击刷新时尝试向东方财富网页批量接口查询最多100只股票，**无需等到16:23定时任务**。部分手机浏览器可能因跨域（CORS）、网络限制或上游限流而失败；失败时保留原行情且明确提示，不会伪造价格。接口不提供SLA，也未承诺长期免费可用。

### 推荐方式：部署一个HTTPS行情代理（一次性）

如遇直连失败，使用仓库中的 [worker/quotes-worker.js](worker/quotes-worker.js) 建立自己的 Cloudflare Worker：

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，打开 **Workers & Pages → Create application → Create Worker → Deploy**。
2. 进入刚创建的 Worker，点击 **Edit code**，用 `worker/quotes-worker.js` 的全部代码替换默认代码，然后保存并部署。
3. 获得自己的 Worker 根网址，例如 `https://investment-quotes.你的子域.workers.dev`，可打开 `https://你的Worker地址/quotes?symbols=600487,002475` 测试。返回含 `quotes` 的JSON代表可获取行情；返回502表示上游暂不可用。
4. iPhone主屏幕App进入 **设置 → 行情自动更新**，填写 Worker 根网址（**不要包含** `/quotes` 或股票代码），点击 **保存行情代理地址**。
5. 在App首页点击右上角刷新，即查询当前观察池及持仓里的所有股票；新增观察股也不用等每日快照更新。

仅会向行情服务发送股票代码，不上传持股数量、成本、现金和融资余额；但观察股票代码本身会被行情服务/代理处理。禁止将券商密码、GitHub Token、持仓JSON等放进URL或公开代码。

「读取GitHub收盘快照」按钮仍在，和盘中查询是两种不同操作。GitHub Actions工作日16:23收盘备份保持不变。

**iPhone重要提示**：代码部署后关闭再重新打开主屏幕App，必要时再次重启以使Service Worker更新。**不要删除App或清除网站数据**，否则本地持仓和风险规则可能丢失。建议先从设置导出JSON备份。

## 每日自动行情如何运行

- `.github/workflows/update_quotes.yml` 在 **北京时间周一至周五 16:23** 自动运行（UTC 08:23），也支持手动执行。节假日同样会运行，报价可能是最近一个有效交易日的收盘价。
- `scripts/update_quotes.py` 从公开可访问的东方财富网页接口逐页采集 A 股最新价、日涨跌幅等数据，以及上证指数历史 MA20、MA60、MA250；存到 `data/quotes.json` 并提交 GitHub 仓库。
- 手机上点击“刷新”只是重新读取已生成的报价快照；不是每秒实时推送或盘中交易所直连。
- 如果全市场接口失败，会尝试少数预置股票回退采集，并将数据源标记为“部分行情”；若全部失败，该次任务报错并保留之前的快照。
- 东方财富网页端接口为**非官方、未经 SLA 承诺的采集方式**，可能随时改变、限流、被阻断，且商业化使用需关注授权条款。如果后续用于大额实盘，建议接入有授权和服务保障的专业行情源。
- `data/quotes.json` 默认没有真实价格。首次运行 Actions 后才会写入真实行情。页面在没有报价时不会伪造仓位数据。

## 使用流程

### 第一步：选择市场阶段

进入「总览」或「风控规则」，将市场分为牛市主升、结构性行情、震荡市、震荡筑底、熊市中的一种。系统也会基于上证指数均线给出**客观参考阶段**，但**不会自动替代你的确认**。

默认融资与仓位风险规则如下（均可编辑）：

| 市场阶段 | 建议融资/净资产 | 融资硬上限 | 股票总敞口上限 | 科技成长单股上限 | 龙头单股上限 | 题材单股上限 |
|---|---:|---:|---:|---:|---:|---:|
| 牛市主升 | 10–20% | 30% | 125% | 15% | 25% | 8% |
| 结构性行情 | 5–15% | 20% | 105% | 12% | 20% | 5% |
| 震荡市 | 0–5% | 10% | 80% | 8% | 15% | 3% |
| 震荡筑底 | 0% | 5% | 60% | 5% | 10% | 2% |
| 熊市 | 0% | 0% | 35% | 3% | 8% | 1% |

这些是**演示性的、偏重风险控制的初始预算**，不是经过针对个人收益、负债、现金流验证的最优值。类别上限也可编辑。由于分类之间可能有高相关性，总上限与类别上限需要一起看。

### 第二步：观察池设定“值得买的价格”

默认观察池预置五个名称供编辑（立讯精密、北方华创、长川科技、特变电工、华润新能），**没有预先编造买入价格或你的当前真实持仓**。每个公司都可以设置行业、风险类别、投资逻辑和三档计划：

- 第一档：跌至 50 元，累计目标仓位 5%；
- 第二档：跌至 45 元，累计目标仓位 10%；
- 第三档：跌至 40 元，累计目标仓位 15%。

以上数字仅说明功能，不是对任何股票的具体建议。达到目标价格时，首页会显示“价格触达”提醒。如果把“研究逻辑有效性”设为“待复核”，自动暂停买价提醒。

### 第三步：输入当前持仓、现金及融资

「持仓」→「添加实际持仓」，输入代码、股数、每股成本，同时输入账户现金、融资负债余额。

系统自动计算：

- **持仓市值**＝最新价 × 股数
- **账户净资产**＝全部持仓市值＋可用现金－融资负债
- **单股净资产仓位**＝该股持仓市值 ÷ 账户净资产
- **类别仓位**＝同类个股持仓市值合计 ÷ 账户净资产
- **股票总敞口**＝全部持仓市值 ÷ 账户净资产
- **融资比例**＝融资负债 ÷ 账户净资产

例：股票市值 1000 万、现金 100 万、融资 400 万，则净资产 700 万、股票总敞口 142.9%、融资比例 57.1%。如果持有未取得报价的股票，系统会标示“待报价”，并**暂停整体仓位计算**以避免低估风险。

**注意**：这里的融资比例不等于券商软件的**维持担保比例**、融资保证金比例或可用保证金，不能替代券商的平仓风控模型。

### 第四步：每日打开主屏幕 App 复盘

查看总览的：最新行情时间、市场阶段、风险提示数量、实际仓位/上限、观察池今日价格，以及当前买价触发情况。

## 本地备份与换手机

- 「设置」→「导出完整JSON备份」包含全部持仓、现金、融资、观察池和个人风险参数。
- 「设置」→「导入JSON」可恢复全部内容。
- 「导出投资汇总CSV」可作为 Excel 或其他数据分析软件的基础材料。
- **不要把 JSON 备份上传到公开仓库，也不要随意转发。**
- Safari 页面与添加到主屏幕后的 Web App 可能有不同的本地存储空间，建议在主屏幕 App 中完成正式数据录入，并定期备份。

## 版本边界 / 下一版建议

**本版已实现**：A股公开行情快照、日线指数参考判别、观察池、三档累计目标买价、分类与单股上限、融资比对、红线提示、本地备份、CSV 导出和 PWA 手机主屏幕体验。

**本版未实现**：自动获取券商持仓、资金流/研究报告/财报估值、交易所直连实时推送、iOS 后台推送、跨设备自动同步、美股自动行情、自动下单。**v1.1新增盘中主动查询（受CORS和上游可用性约束）以及可选的自建HTTPS行情代理。**V2 可将估值与技术入场条件纳入每档买价，加入多账户聚合、A股与美股分币种风控、股价/财报条件推送、组合风险和回测。

## 本地测试

如果有电脑，可在本目录执行：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。由于首次行情数据为空，可在股票编辑中输入“手动行情价”测试本地规则；手动价会覆盖自动行情，正式使用时记得清空。

## 安全建议

1. 使用可信的 GitHub Pages 域名，不要输入证券账户密码、交易验证码、API Token。
2. 使用有密码保护的 iPhone；PWA 中的持仓属于普通本机浏览器存储，并非加密保险箱。
3. 基本面大幅变化、退市风险、停牌、除权、跨币种、行情延迟会使固定价格阈值失效。系统不会替你核验投资逻辑。
4. 重要融资决策以券商账户实时数据、合同和自身资金需求为准。
