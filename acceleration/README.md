# 盈利加速股扫描器 V1.0（独立研究）
冻结初始规则，不以回测结果反复调参。最新共同时点：Q1 4/30、Q2 8/31、Q3 10/31；Q4作为计算序列不在与Q1重合的4/30重复开仓。累计扣非归母利润、营业收入、合并净利润、经营现金流自主拆分为单季；同季度同比消除季节性的主要影响。连续3个同比比较期两侧收入和利润必须为正，去年同季扣非利润至少1000万元且扣非利润率至少1%。最新季度营收同比至少10%、扣非利润率同比改善至少1pp、TTM经营现金流/合并净利润至少80%。金融企业排除；当前截面排除ST/退市名称，历史截面不使用现有公司名单。
持续加速：最新扣非同比≥30%，最新增速较前季至少+10pp，前季增速较再前季至少+5pp。初现加速：最新同比≥20%，前季同比<20%，改善≥20pp；两者重合优先持续加速。两种均要求已盈利，不把扭亏作为同一种信号。不设ROIC或PE硬门槛，以免与成长股模块重复。展示最新收盘价、PE及市值，不据此排序或产生买点。
数据：Tushare income_vip/fina_indicator_vip/cashflow_vip、trade_cal、daily_basic、adj_factor、stock_basic。历史选择公告/实际公告不晚于截面，解决兼容字段超集、拒绝同日矛盾；供应商历史修订和覆盖不保证原始点时数据。历史2022Q1—最新共同时点，按同日期同数量最高当季扣非增长率做基线（共享质量门槛），报告重叠度。下一季/下下季实际扣非同比（保留未来亏损）、下一交易日收盘入场后的20/60交易日调整价格收益；两组覆盖≥80%才计入逐期差异，未考虑涨跌停、交易成本、退市回款等，未做独立验证集及显著性推断。不能称可交易策略、未来预测或真实点时回测。股价只是研究辅助。研究结果不更改现有正式工具，逐股结果加密，公开日志只有汇总。
研究参考：He & Narayanamoorthy, Earnings acceleration and stock returns (2020), JAE；Novy-Marx, Fundamentally, Momentum is Fundamental Momentum (2015), NBER w20984。阈值为本工具初始假设，非论文直接复制。
